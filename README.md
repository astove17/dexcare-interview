# SRE Interview

## Your task

Deploy the Helm chart in `./resources/chart/` and fix the issues you find.

*Think out loud.*
- Deploy the chart to your namespace of choice
- Identify the issues
- Fix the issues by editing chart templates
- Verify the service is working

## Files

```
resources/
└── chart/
    ├── Chart.yaml
```
